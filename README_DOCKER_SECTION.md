## Running locally with Docker (2 minutes)

Prerequisites:
- Docker and Docker Compose
- [Ollama](https://ollama.com) installed and running on your host machine
  (not containerized -- see `Dockerfile.backend` for why)
- A [Gemini API key](https://aistudio.google.com/apikey) and a
  [GitHub personal access token](https://github.com/settings/tokens)
  (classic, no special scopes needed for public repos)

```bash
# 1. Pull the local summarization model (one-time, ~1GB download)
ollama pull qwen2.5-coder:1.5b

# 2. Configure credentials
cp .env.example .env
# edit .env and fill in GEMINI_API_KEY and GITHUB_TOKEN

# 3. Build and start everything
docker compose up --build
```

Once running:
- **Frontend**: http://localhost:5173 -- pre-seeded repositories (`httpx`, `got`, `requests`, `itsdangerous`, `bottle`) are ready to query instantly with zero wait time. You can also paste any public GitHub repository URL to ingest new repos live.
- **Backend API docs** (interactive, auto-generated by FastAPI):
  http://localhost:8000/docs

To start completely fresh (wipe all ingested data):
```bash
docker compose down -v
```

**Known constraint**: ingestion speed depends heavily on your host
machine's CPU, since symbol summarization runs a local LLM
(`qwen2.5-coder:1.5b`) via Ollama with no GPU acceleration assumed. On
modest hardware, a small repo (10-20 files) takes roughly 1-3 minutes end
to end; larger repos take proportionally longer. This is a deliberate
trade-off documented in `ARCHITECTURE.md` -- it keeps the whole stack
runnable on a laptop with no paid inference API for this step, at the
cost of ingestion speed.
